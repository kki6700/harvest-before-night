# Lantern Harvest — 개발 기록 (2차 Unity 평가)

## 10/22 씬 구성
- 새 프로젝트 `02_Unity_Eval` (Unity 6000.3.24f1, URP). 1차 이전부터 해 온 개인 프로젝트(DSEWA_63, 1차 제출 에셋 포함)의 설정 · 아트를 GUID 그대로 복사, 팀 프로젝트에서 직접 만든 작물(등불 열매 3단계 · 버섯꽃 3종 · 공용 성장 애니메이션)과 최신 셰이더만 추가.
- 문제 1: 팀 작물 일부가 1차 에셋을 이름만 바꾼 복사본이라 GUID가 겹침 → Unity가 한쪽에 새 GUID를 붙여 프리팹 머티리얼 68개가 빈칸이 됨. 겹치는 옛 파일을 지우고, 남긴 파일을 프로젝트 밖으로 뺐다 다시 넣어 원래 GUID로 등록되게 해서 해결.
- 문제 2: 지형 데이터 `TD_LookDev.asset`이 더 최신 Unity(6000.6)에서 저장돼 열리지 않음 → 씬은 이미 `TD_LookDev_DeepBlue`를 쓰고 있어 영향 없음 확인.
- `Stage1` 씬: 배경 씬(하늘 · 구름 · 지형 · 안개 · 크리스탈 · 버섯 · 호수 · 낮/밤 전환)을 바탕으로 테스트 물체 정리, 밭 6개(4 × 4 m, 칸 24) + 등불 열매 · 버섯꽃(완성 / 자라는 중 섞음), 플레이어 = SD 고양이(Idle / Walk / Run 애니), 3인칭 카메라, 시작 시각 오후 2시.
- 외계인 손님(Cunsumer, 1차 직접 제작: 얼굴 리토폴 · 옷 · 21본 리그 · Mixamo 걷기 · 툰 셰이더)을 납품 상대로: 가게 문 · 손님 · 바구니를 함께 밭 오른쪽 옆(문 (12.5, 0, -6.5))으로 옮기고 플레이어 시작점 쪽을 보게 돌림. 처음 (9.5, 0, -1.5)은 밭과 겹쳐서 다시 옮김.
- 콘솔 에러 정리: (1) 1차 · 팀 복사본이 같은 GUID를 가진 파일 7개(꽃 등불 열매 모델 · 재질, 수확 아이템)가 Unity DB에서 다른 GUID로 등록돼 배경 씬 프리팹이 끊김 → 폴더를 잠깐 빼고 다시 넣어 원래 GUID로 재등록, 프로젝트 전체 DB/meta GUID 불일치 0 확인. (2) 열리지 않는 6000.6 지형 파일 2개(안 쓰임) 삭제. (3) URP 전역 설정에 남은 최신 URP 전용 타입 6개 제거(ClearAllManagedReferencesWithMissingTypes). (4) 셰이더 Properties의 Header 문구에 쉼표 · 괄호가 있어 drawer 생성 실패 → 영문자 · 숫자만 남김. 처음에 -, / 로 바꿨다가 셰이더 13개가 파싱 에러(이름 빈칸, 지형이 안 그려짐) → 원본으로 되돌리고 다시 정리. (5) ToonFoliage 경고(조기 return으로 초기화 안 된 변수) → if 블록으로 바꿈. (6) 구름 3D 텍스처 이름 불일치 수정. 플레이 모드 에러 · 경고 0.

- 발 미끄러짐(사용자: "발이 계속 미끄러지니 애니메이션 해결해줘"): 재 보니 원인이 셋.
  1. 고양이 클립: 디딘 발이 땅을 미는 속도가 1배속에서 0.54 m/s인데 재생 1.6 / 2.2배에 이동 2.2 / 4.2 m/s라 2.5~3.5배 미끄러짐. 게다가 Blender에서 재 보니 앞발은 가장 낮을 때도 땅보다 4.5 cm 떠 있었고 48개 샘플 중 1~3개만 땅에 닿음(몸의 뜀 · 기울기 때문에 발이 공중을 휘저음).
  2. Unity 클립 범위가 옛 17프레임 시절 설정(0~16)으로 남아, 12프레임 클립 끝에서 4프레임 동안 멈췄다 반복.
  3. 손님: 걷기 클립 속도는 맞았지만 2.9초짜리 걷기 시작(WalkStart) 동안에도 전속력으로 이동.
  - 고친 것: 질주를 24프레임으로 다시 짜서 각 발이 주기의 1/8(3프레임) 동안 땅 높이에 붙어 ±9 cm를 일정 속도로 밀고, 그동안 몸을 2.5~3 cm 낮춰 늘리지 않은 다리가 땅에 닿게 함. 앞발은 굽은 아래다리를 따라 발끝이 땅 밑 3.3 cm로 파고들어서, 프레임마다 발 뼈를 평평한 방향으로 다시 키. 휘두르는 발이 낮은 몸 아래에서 가슴을 파고들어 구겨지던 것도 들기 높이를 낮춰 해결. Blender에서 네 발 모두 땅 높이 · 일정 속도 확인, 눌린 면 58 → 38.
  - Unity: 클립 범위 0~24로, `CatController`가 재생 속도 = 이동 속도 ÷ 발이 땅을 미는 속도(FBX에서 0.76 m/s)로 자동 맞춤 → 걷기 1.6 m/s(2.1배) · 달리기 2.8 m/s(3.7배). 이제 클립이 직접 뛰므로 코드로 더하던 통통 뛰기 · 착지 눌림은 0으로.
  - 손님: 클립의 루트 모션 거리만큼만 몸을 옮기고(OnAnimatorMove) 방향만 코드로 → 걷기 시작이 천천히면 몸도 천천히.
  - 측정 과정의 실수: Unity에서 발바닥 정점을 고르는 측정 도구가 스케일을 두 번 곱하고 발바닥 대신 손목 쪽 정점을 골라 값이 틀림 → FBX를 Blender로 다시 불러 원본과 0.532배로 같음을 확인하고 그 수치로 계산, 측정 도구는 지움. 이미지 23.
- 버섯꽃(사용자: "수확하면 제거되고 자라는 것까지만"): 전에는 25 %로 줄어든 채 남았음 → 수확하면 살짝 부풀었다가 0으로 줄어 사라지고(렌더러 끔), 다시 자랄 때가 되면 마지막 3초 동안 땅에서 0 → 108 % → 100 %로 솟아오름. 다시 자라는 시간(18초)은 그대로. 이미지 24(테스트용으로 6초).
- 플레이 영상: 실행 옵션 `-demo`를 주면 고양이가 스스로 가까운 익은 작물로 달려가 수확하고, 바구니가 차거나 익은 작물이 없으면 손님에게 납품하는 시연 모드(`DemoAutopilot`, 키 입력과 같은 경로로 움직임). 에디터에서 44초에 손님 3명 · 220원 확인. 빌드를 `-demo`로 전체 화면 실행하고 Windows 기본 녹화(Win + Alt + R)로 1분 22초 녹화. 옵션 없이 실행하면 평소 게임.
