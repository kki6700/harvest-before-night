직접 만든 외계 행성 배경 위에서, 짧고 분명한 한 판

1차 평가에서 만든 외계인 손님 · 등불 열매 · 가게 문과, 그 전부터 개인 프로젝트로 직접 만들어 온 외계 행성 들판(하늘, 구름, 지형, 수정, 버섯, 호수)이 있었습니다. 이 에셋들이 "살아 있는 곳"처럼 보이도록, 가장 단순한 농장 가게 놀이를 하나 얹었습니다.

플레이어는 바구니 손잡이를 입에 문 작은 고양이입니다. 밭에서 등불 열매와 버섯꽃을 수확해, 가게 문 앞에 차례로 찾아오는 손님의 주문을 채웁니다. 오후 2시에 시작해 밤 10시가 되면 끝나고, 그 사이 하늘이 실제로 저물어 남은 시간을 눈으로 느끼게 했습니다.

핵심 반복

수확익은 작물 앞에서 E — 고개를 숙여 수확하면 열매가 바구니로 날아감
→
나르기바구니는 12개까지. 가득 차면 손님에게
→
건네기주문에 필요한 만큼만 건네고, 남은 열매는 다음 손님 몫
→
벌기주문을 다 채우면 돈 + 보너스, 옷 색이 다른 다음 손님 등장

목표와 끝

밤 10시 전에 500원을 벌면 성공, 그 전에 밤이 오면 실패입니다. 수확한 작물은 잠시 뒤 다시 자라서, 어떤 작물부터 수확할지 길을 고르는 재미가 생깁니다.

이렇게 정한 이유

  • 1차 에셋과 직접 만든 에셋을 최대한 그대로 쓰면서 "왜 여기 있는지"가 보이게
  • 조작은 이동과 E 하나 — 처음 해도 10초 안에 이해
  • 시간 제한을 하늘 변화로 보여 줘서 UI 없이도 긴장감

시간이 흐르는 하늘과 3인칭 카메라

조명 · 배경

배경과 함께 직접 만든 낮/밤 시스템(태양 · 구름 빛 · 안개 · 포자 · 밤 후처리)을 게임 시계에 연결했습니다. 시간이 흐르면 하늘과 조명이 함께 저물어, 화면만 봐도 남은 시간을 알 수 있습니다.

카메라

고양이 뒤 위쪽에서 따라가는 3인칭 카메라입니다. 마우스 오른쪽 드래그로 돌리고 휠로 줌합니다. 이동 방향은 카메라 기준이라 어느 쪽을 보든 W가 "화면 안쪽"입니다.

화면 정리

  • 밭과 가게 문 앞을 풀 생성기의 제외 영역에 넣어 풀이 흙을 뚫지 않게
  • 게임 화면 전체가 초록으로 물들던 색 문제를 찾아 해결 (9쪽)

GameDirector — 한 판의 상태와 시간

// 상태: 시작 화면 → 플레이 → (일시 정지) → 성공 / 실패
public enum State { Ready, Playing, Paused, Won, Lost }

// 게임 시각: 경과 시간을 오후 2시 ~ 밤 10시로 바꿈
public float Hour => Mathf.Lerp(startHour, endHour, Elapsed / roundSeconds);
void Update()
{
    switch (Current)
    {
        case State.Ready:                          // Enter로 시작
            if (kb.enterKey.wasPressedThisFrame) Begin(); break;
        case State.Playing:
            if (kb.escapeKey.wasPressedThisFrame) { Pause(true); break; }
            Elapsed += Time.deltaTime;
            dayNight.hour = Hour;                    // 배경의 낮/밤 시스템을 시계로 움직임
            if (Elapsed >= roundSeconds) SetState(State.Lost);  // 밤 10시 = 실패
            break;
        case State.Won: case State.Lost:            // R로 다시 하기
            if (kb.rKey.wasPressedThisFrame) Restart(); break;
    }
}
// 손님이 돈을 낼 때마다 불림 — 목표 금액이면 성공
void OnPaid(int coins, int gained)
{
    if (Current == State.Playing && coins >= goal) SetState(State.Won);
}
void SetState(State s)
{
    Current = s;
    Time.timeScale = s == State.Paused ? 0f : 1f;    // 일시 정지는 시간을 멈춤
    cat.gameLocked = s != State.Playing;             // 플레이 중에만 고양이 조작
    StateChanged?.Invoke(s);                         // UI가 패널을 바꿈
}

읽는 법

  • 게임 전체를 상태 하나로 관리합니다. 키 입력도 상태마다 다르게 받습니다.
  • 시간은 Elapsed 하나로 재고, 그걸 시각으로 바꿔 하늘에 넘깁니다. 시계 UI도 같은 값을 읽습니다.
  • 승리는 "돈이 들어오는 순간"에만 확인합니다. 매 프레임 검사하지 않아 단순합니다.
  • 상태가 바뀌면 이벤트를 보내고, UI는 그걸 듣고 패널을 켜고 끕니다. 규칙과 화면이 서로를 몰라도 됩니다.

고양이 잠금을 따로 둔 이유

수확 동작은 끝날 때 고양이 잠금을 풉니다. 게임이 끝난 직후 수확이 마무리되면 결과 화면에서 고양이가 다시 움직였습니다. 그래서 게임 상태 전용 잠금(gameLocked)을 따로 두었습니다.

// DeliveryPoint — 고양이가 열매를 건넬 때
public int Receive(int amount)
{
    if (!IsReady || amount <= 0) return 0;   // 손님이 없으면 못 받음
    int take = Mathf.Min(amount, Order - Filled); // 주문에 필요한 만큼만
    Filled += take;
    Delivered += take;
    customerAnimator.SetTrigger("PickUp");      // 손님이 받는 동작
    if (Filled >= Order) StartCoroutine(PayAndLeave());
    return take;                                  // 남은 건 바구니에 그대로
}

IEnumerator PayAndLeave()
{
    int gained = Order * pricePerFruit + orderBonus;
    Coins += gained;
    Paid?.Invoke(Coins, gained);                 // 승패 판정 · "+n원" UI

    ...
    NewLook();                                   // 코트 · 셔츠 · 바지 색만 바꿈
    NewOrder();                                  // 주문 4~9개
    yield return WalkTo(_standPos);             // 문에서 걸어 나옴
}
// CatController — 달리기 애니메이션 재생 속도
// 디딘 발은 1배속에서 초당 pawGroundSpeed만큼 땅을 밉니다.
// 몸이 그 속도로 나아가면 발이 땅에 붙어 보이므로,
// 재생 속도 = 이동 속도 ÷ 발이 미는 속도
float synced = _planarSpeed / Mathf.Max(0.05f, pawGroundSpeed);
animator.speed = !moving ? 1f : Mathf.Max(0.5f, synced);

// DeliveryPoint — 손님 걷기는 클립의 이동량(루트 모션)만큼만
void OnAnimatorMove()
{
    if (!_walking) return;
    float step = customerAnimator.deltaPosition.magnitude;
    Vector3 d = _walkTarget - transform.position; d.y = 0f;
    // 길 방향으로만, 목표를 넘지 않게
    transform.position += d.normalized * Mathf.Min(step, d.magnitude);
}
